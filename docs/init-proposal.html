司法正義 AI 三模組技術提案書

一、目標與目的

  • 透過 AI agent 推動反廢死與打擊司法貪腐的雙重目標。
  • 建立自動化系統以提升輿情掌握、論述生成與司法資料分析能力。
  • 強化民間監督與社群動員能力，促進法治與正義落實。

二、方案選擇比較與決策

模組 技術難度 成本 社會影響力 優先性
輿情監測 低 低 高 ⭐️⭐️⭐️⭐️
論述生成器 中 中 高 ⭐️⭐️⭐️⭐️
判決分析 中高 中 高 ⭐️⭐️⭐️⭐️

根據技術可行性與社會回報比，決策優先開發上述三模組。

三、模組規劃架構

模組一：輿情監測模組

  • 資料來源：PTT、Facebook、Google News
  • 技術組成：Scraper + BERT 情緒分析 + PostgreSQL + Streamlit

模組二：反廢死論述生成器

  • 技術組成：GPT-4 + Prompt Template + 社群 API

模組三：判決資料分析模組

  • 資料來源：司法院法學資料庫
  • 技術組成：LexNLP + 判決抽取 + 統計分析 + Superset

四、AWS 架構圖（文字版）

  • 使用 AWS EC2 部署 FastAPI 後端
  • 使用 AWS RDS（PostgreSQL） 儲存分析資料
  • 使用 AWS S3 儲存爬蟲原始資料與生成內容
  • 使用 AWS Lambda 處理定時任務（如每日輿情摘要）
  • 使用 AWS CloudWatch 監控系統運作

五、開發任務分工表（4週）

週次 任務內容
第1週 資料來源串接（PTT、判決書）、Prompt設計
第2週 NLP模型訓練與測試、資料庫建置
第3週 視覺化儀表板開發、論述生成介面
第4週 API整合、社群發布串接、測試與部署
