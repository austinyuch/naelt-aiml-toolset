# Facebook 平台要求

## 平台特性

Facebook 適合較長篇幅的論述和深度討論，使用者願意花時間閱讀完整的內容，並參與留言互動。

## 格式限制

- **最大字數**: 2000 字（建議 500-1200 字）
- **標籤數量**: 0-5 個（建議 0-3 個，Facebook 較少使用標籤）
- **風格**: 段落分明，論述完整，適合深度討論

## 內容結構

1. **引言**（2-3 句話）

   - 簡要說明議題背景或引發討論的事件
   - 點出文章的核心關切
   - 可使用問句引發思考

2. **分段論述**（3-5 段）

   - 每段聚焦一個論點或面向
   - 段落之間邏輯連貫，層層遞進
   - 適當引用數據、案例或專家觀點
   - 段落長度適中（3-5 句話）

3. **結論與呼籲**（2-3 句話）

   - 總結核心觀點
   - 提出具體的行動建議或思考方向
   - 鼓勵讀者分享、留言或參與討論

4. **標籤**（可選，放在最後）
   - 僅使用最相關的標籤
   - 避免過多標籤，以免顯得不專業

## 寫作技巧

- **完整論述**: 提供充分的背景資訊和論證
- **邏輯清晰**: 論點之間的連結要明確，避免跳躍
- **數據支持**: 適當引用統計數據、研究結果或案例
- **平衡觀點**: 可以提及不同立場，但清楚表達自己的觀點
- **段落分明**: 使用空行分隔段落，提升可讀性
- **引發討論**: 提出開放性問題，鼓勵讀者留言互動
- **語氣適中**: 保持理性和專業，避免過度情緒化

## 互動策略

- **提問**: 在文末或段落中提出問題，邀請讀者分享看法
- **分享呼籲**: 鼓勵讀者分享文章，擴大影響力
- **回應留言**: 預期會有留言討論，內容應能引發有意義的對話
- **連結資源**: 可以附上相關新聞連結、報導或資料來源

## 標籤使用

- Facebook 較少使用標籤，標籤不是主要的內容發現方式
- 如果使用標籤，應選擇最核心的 1-3 個
- 標籤應放在文末，不影響正文閱讀

## 圖片建議指引

- 可使用新聞圖片、資訊圖表或象徵性圖像
- 圖片應能補充文字內容，提供額外資訊
- 考慮使用多張圖片組成相簿，呈現更完整的資訊
- 圖片說明（caption）可以補充重要資訊

## 範例結構

```

[論述段落一]

[論述段落二]

[論述段落三]

[結論與呼籲]

你怎麼看這個議題？歡迎在留言區分享你的想法。

#標籤1 #標籤2（可選）
```
