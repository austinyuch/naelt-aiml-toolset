# LINE 平台要求

## 平台特性

LINE 是即時通訊平台，使用者習慣快速閱讀和轉發訊息。內容需要極度簡潔，一眼就能掌握重點。

## 格式限制

- **最大字數**: 200 字（建議 50-150 字）
- **標籤數量**: 0-3 個（建議 0-2 個）
- **風格**: 極簡短，易轉發，一句話重點

## 內容結構

1. **核心訊息**（1-2 句話）

   - 直接點出最重要的訊息
   - 使用簡潔有力的語言
   - 可使用 emoji 增加視覺效果

2. **簡短標籤**（可選）
   - 僅使用最核心的 1-2 個標籤
   - 標籤應簡短易記

## 寫作技巧

- **極度精簡**: 每個字都要有意義，刪除所有冗餘
- **重點突出**: 只保留最核心的訊息
- **易於轉發**: 內容應該讓人想要分享給朋友
- **情感衝擊**: 用簡短的文字創造情感共鳴
- **行動導向**: 如果有行動呼籲，要非常明確簡潔
- **適度使用 emoji**: 可以用 emoji 代替部分文字，節省字數

## 訊息類型

### 1. 新聞摘要型

- 快速傳達新聞重點
- 格式：[事件] + [關鍵訊息] + [簡短評論]

### 2. 觀點表達型

- 清楚表達立場
- 格式：[核心觀點] + [簡短理由]

### 3. 行動呼籲型

- 鼓勵具體行動
- 格式：[問題] + [行動呼籲]

## 標籤使用

- LINE 訊息中標籤不是主要元素
- 如果使用，應選擇最簡短、最核心的標籤
- 標籤可以幫助訊息分類，但不應佔用太多字數

## 圖片建議指引

- 圖片應該能夠獨立傳達訊息
- 考慮使用文字圖片（圖片中包含關鍵文字）
- 圖片應該在小螢幕上也清晰可讀
- 簡單明瞭的視覺設計

## 轉發考量

- 內容應該讓人願意轉發給朋友或群組
- 避免過於爭議或攻擊性的語言
- 訊息應該完整，不需要額外解釋
- 考慮訊息在群組中的傳播效果

## 範例結構

### 範例 1（新聞摘要）

```
💔 [事件簡述]
這就是為什麼我們需要改變。
#司法正義
```

### 範例 2（觀點表達）

```
[核心觀點] 🔥
[簡短理由]
```

### 範例 3（行動呼籲）

```
[問題描述]
一起 [具體行動] 👊
```

## 注意事項

- 字數限制非常嚴格，必須精簡再精簡
- 每個字都要有價值，避免修飾語
- 使用 emoji 可以節省字數並增加視覺效果
- 內容應該完整，不需要點擊連結才能理解
- 考慮訊息在不同裝置上的顯示效果
